# Aura Player — лендинг

Одностраничный сайт о кроссплатформерном музыкальном плеере **Aura Player**
(Wails v2 + Go + React), собранном из проекта `C:\Users\galae\Audio player`.

## Как открыть

Просто откройте `index.html` двойным щелчком — сайт полностью статический,
работает без сервера и сборки. Для локального сервера:

```powershell
# из папки сайта
python -m http.server 8080
# затем откройте http://localhost:8080
```

## Структура

```
index.html                  разметка всех секций
css/style.css               дизайн-система, адаптив, анимации
js/main.js                  WebGL-аура, reveal, демо-плеер, табы, лайтбокс
assets/aura-icon.png        иконка приложения (1024×1024)
assets/aura-icon-256.png    favicon
assets/screens/*.webp       реальные скриншоты приложения v1.2
download/AuraPlayer-1.2-Windows-x64.exe   сборка для скачивания
```

## Секции

1. **Hero** — заголовок, ключевые тезисы, схема интерфейса плеера, бегущая строка источников.
2. **Статистика** — 6 источников, 11 жанровых фильтров, 10 полос EQ, предзагрузка 75 %, WebGL-фон.
3. **Возможности** — bento-сетка из 8 карточек (USL fallback, Моя Волна, Fluid Aura, DSP, тексты, Discord RPC, локальные файлы, мини-плеер).
4. **Интерактивное демо** — рабочий прототип плеера: переключение треков, пауза, перемотка, лайки, спектр, смена цветов ауры.
5. **Интерфейс** — вкладки с UI-реконструкцией экранов приложения.
6. **Скриншоты** — 6 реальных кадров приложения с лайтбоксом.
7. **Технологии** — Wails, Go, React, Vite, Tailwind, WebGL.
8. **Скачивание** — кнопки релиза, шаги установки, список ОС.
9. **FAQ** и финальный призыв к действию.

## Особенности реализации

- **WebGL-аура**: собственный фрагментный шейдер на симплекс-шуме (тот же алгоритм, что в приложении), реагирует на движение курсора; есть CSS-fallback и поддержка `prefers-reduced-motion`.
- **Анимации**: переопределение появления блоков через `IntersectionObserver`, счётчики, tilt-эффект карточек, бегущая строка, пульсирующие акценты.
- **Демо-плеер**: 6 треков, кастомная перемотка (pointer events), перемешивание, лайки, визуализатор на 42 полосы, цвета ауры вычисляются из обложки.
- **Доступность**: семантика `main`/`section`/`footer`, alt у изображений, `aria-*` у кнопок и табов, закрытие лайтбокса по Escape, тач-таргеты ≥ 28 px.
- **Адаптив**: проверено на 1440 / 1280 / 1024 / 768 / 390 px — без горизонтальной прокрутки.

## Обновление данных

- **Новая версия сборки**: замените файл в `download/` и поправьте подписи `13 МБ` / `v1.2` в `index.html`.
- **Новые скриншоты**: положите `.webp` в `assets/screens/` и добавьте кнопку `.shot` в секцию `#gallery`.
- **Ссылка на другой релиз**: массово замените `download/AuraPlayer-1.2-Windows-x64.exe`.

## Источники контента
